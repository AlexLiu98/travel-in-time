# Travel in Time — Guest Edition

A public, account-free travel footprint map. Visitors can mark countries and cities, view world and China maps, and export or import their data.

Travel records are stored only in each visitor's browser. Clearing browser data may remove them, so regular JSON exports are recommended.

## Publishing

GitHub Pages is deployed automatically from the `main` branch by the workflow in `.github/workflows/pages.yml`.
