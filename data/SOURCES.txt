Boundary data sources

- World countries and territories: Natural Earth Admin 0 map units (public domain), using 1:50m geometry for display and 1:10m geometry for precise land and island hit testing; both are pinned to a specific revision, with the bundled low-resolution copy as a fallback.
  https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_50m_admin_0_map_units.geojson
  https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_10m_admin_0_map_units.geojson
- China provincial boundaries: Alibaba Cloud DataV geographic boundary service.
  https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
- ISO alpha-2/alpha-3 mapping: country-data package (MIT License).
  https://www.npmjs.com/package/country-data
- City search and map labels: GeoNames cities500 dataset (CC BY 4.0).
  Han-script names are preferred for display when available; local and Latin names remain searchable.
  https://download.geonames.org/export/dump/
- Leaflet 1.9.4 is bundled locally (BSD 2-Clause License).
  https://leafletjs.com/
  See ../vendor/leaflet-LICENSE.txt
